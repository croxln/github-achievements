# 🛠️ Paper Dev Toolkit

A modular collection of lightweight Java utilities, Kyori Adventure MiniMessage helpers, and event adapters designed for modern PaperMC (1.21+) server development.

## 📦 Features

- **Text & MiniMessage:** Simplified color handling and gradient parsers.
- **Async Schedulers:** Safe cross-version Folia/Paper task wrappers.
- **Inventory & GUI:** Lightweight holder abstractions without heavy external frameworks.
- **NBT / PDC:** Type-safe persistent data container wrappers.

## 🚀 Usage

`gradle
repositories {
    mavenCentral()
}

dependencies {
    compileOnly("io.papermc.paper:paper-api:1.21.4-R0.1-SNAPSHOT")
}
`
